## 实际输出与限制

1. Luna 文字测试约 9.94 秒，真实视觉输入约 7.17 秒。另测 max_tokens:128 约 2.69 秒成功；max_completion_tokens 在前两次调用也成功。本轮时间仅为单次观测，不是性能基准。
2. 出图请求 n=1、size=1024x1024、quality=low；保存的实际 PNG 是 **1374×1145**、1,239,712 字节。响应 size 也为 1374x1145，说明本次服务没有遵循请求尺寸。布局/导出需基于实际尺寸或显式缩放，不能假定返回正方形。
3. 保存图片约 23.98 秒返回。人工查看工具已显示 PNG；随后 Luna 识别为机器人在桌前读书、青绿色点缀、没有可见文字。
4. 总计发送 **两次**图片生成请求：第一次 HTTP 200，但本机后台输出回调异常导致未保留图片；第二次为明确的产物验证重试，已保存。该回调错误不是模型拒绝或服务失败，不能据此统计模型失败率。
5. 本轮证明直接 API 的文字、视觉及出图能力；**尚未证明应用浏览器内完整漫画生成、保存、复审、导出流程**。连接测试的图片解码单测使用 mock，不等同于真实浏览器验收。
6. 仅做最小样本，不代表多轮一致性、长上下文、并发、流式、取消、内容准确率或尺寸参数都已兼容。
