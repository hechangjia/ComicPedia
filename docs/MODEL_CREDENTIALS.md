# 模型密钥生命周期（2026-09-20）

## HTTP 与保存语义

LLM、VLM、文生图配置的 GET `/api/config` 返回 `apiKey: ""` 与 `hasApiKey`，不返回已保存的 key，也不返回 key 后缀。数据库内仍需要保存用于服务请求的实际凭据；本批不引入静态加密，也不是认证/授权方案。

PUT `/api/config` 仍要求 If-Match：

| 请求 | 结果 |
| --- | --- |
| apiKey 为空或省略 | 按相同角色及 ID 保留旧密钥 |
| apiKey 有新值 | 替换为去除首尾空白的新密钥 |
| clearApiKey=true | 明确清除旧密钥 |
| 同时给新值与清除标记 | 400，拒绝矛盾操作 |
| 有旧密钥、地址或协议改变，但未替换/清除 | 400，要求确认凭据操作 |

hasApiKey 由服务器实际凭据计算，不能靠客户端标记创建认证信息。不同角色即使 ID 相同也不会互相取用密钥。

## 设置与请求

- 编辑时已保存的密钥输入框为空；文案解释保留、替换和清除。无认证的本地文生图服务允许留空。
- 已保存配置的能力测试使用服务器引用；未同步完成时设置页要求先保存，不把旧服务器配置的测试结果当成当前草稿的能力。
- 模型发现可使用保存的角色引用。服务器拒绝通过引用把旧密钥发送到修改后的地址或协议；新输入凭据的草稿可单独测试。
- 模型发现主请求拒绝重定向，错误日志不记录上游原文；返回体采用大小受限读取。
- 带密钥/引用的模型发现不存入长期内存 Map 缓存，避免 key 被作为缓存字符串长期保留或出现陈旧凭据结果。

## 浏览器内存与恢复

- 新输入在保存前仅驻留页面内存；服务器确认后清除该次输入，不覆盖并发输入的新值。
- localStorage / sessionStorage 新写入的模型配置剔除 API key。待保存的密钥输入被标记为 apiKeyInputRequired。
- 保存失败后可在本页重试；若刷新导致新输入丢失，则要求重新输入或明确清除，不自动提交缺失密钥的草稿。迁移接口同样拒绝这种不完整草稿。
- 可解析的旧模型配置备份在下次缓存写入时按相同规则去除 key；未加载的旧浏览器、其他标签页、无法解析的历史备份不在此轮自动擦除保证范围内。旧格式的一次性迁移可能在内存暂存原 key，直到同步成功。
- 本批精确范围是三个模型列表的 apiKey 字段。Accuracy Provider 的编辑生命周期、任意工作流或扩展字段内嵌秘密、所有历史缓存全局清理仍需分别治理。不能据此声明浏览器中不可能存在任何秘密。

## 验证

- 单元/路由：三角色脱敏及角色隔离、保留/替换/清除、目标变化拒绝、保存确认与并发输入、缓存缺失输入恢复、模型发现引用、设置测试引用、组件语义、迁移保护。
