# 配置导入导出契约

## 范围与格式

设置页配置传输包含文字脚本（LLM）、视觉复审（VLM）、文生图、检索 Search/Fetch 服务、默认角色和域名白名单。与漫画作品的 PNG/PDF/ZIP 出版导出、完整作品备份是不同功能。

新 JSON 格式：app=comicpedia、type=config、formatVersion=1、version=2，模型列表为 llmConfigs / vlmConfigs / imageConfigs，检索配置为 accuracyConfig。文件上限 2 MiB；每个配置列表最多 200 项。兼容旧 V1 单配置、旧 V2 多配置和此前的单类配置导出。其他应用、未知版本、无效条目、重复 ID、悬空引用或检索角色能力错配会拒绝整次导入。

## 敏感内容

- 默认导出采用字段白名单，排除 API Key、掩码、历史健康状态/错误、浏览器同步元数据和未知扩展字段。
- 自定义 ComfyUI 工作流默认排除；单独勾选后才包含。任意工作流可能内嵌令牌，不能保证脱敏，文件会记录 omittedWorkflows 或 embeddedWorkflowsIncluded。
- apiKeyFieldsIncluded=false 只说明 API Key 字段被排除，不保证用户填写的名称、提示词或主动包含的工作流不含私人内容。
- 导入旧文件中的密钥默认关闭，需在预览中明确勾选；工作流另有独立确认。导入不会运行任何模型或工作流。
- 导出不提供一键明文密钥备份。已在服务器保管的检索凭据不通过导出取回；迁移到新环境需重新填写所需密钥。

## 合并规则

选择文件只解析和预览，不改变配置。确认后在当前最新草稿上一次性合并，经既有串行保存与版本校验同步到服务器。

1. 新增条目分配独立 ID；源文件 ID 仅用于本次角色引用重映射，不可指向本机其他凭据。
2. 重复条目按连接/模型等配置语义识别；现有配置内容和密钥不被覆盖，重复数明确展示。
3. 现有默认模型与检索角色保持不变；未分配的角色采用文件中的合法选择。域名白名单取并集。
4. 导入排除凭据/工作流后的重复检查可重复执行，不连续制造相同配置。
5. 超过总数限制、验证失败或 ID 无法生成时不修改草稿，不发送部分保存。取消或 Escape 也不保存。
6. 预览与最终确认之间若有其他本地编辑，最终合并重新基于最新 store 计算，不使用旧预览快照覆盖。

## 已知边界

配置 JSON 不是完整凭据备份，也不包含漫画作品或图片资产。默认导出的 ComfyUI 配置需要补充工作流；需要授权的模型需填写密钥，能力测试需重新执行。服务器 GET 的模型密钥脱敏、浏览器凭据隔离以及服务端角色 ID 解析尚属后续架构工作，本功能不构成认证或授权保护。
