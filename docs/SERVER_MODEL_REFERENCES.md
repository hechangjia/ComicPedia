# 服务端模型引用（2026-09-20）

## 本批范围

已保存配置的浏览器生成请求使用 `{ modelRef: { id, role }, payload }`。角色为 `llm`、`vlm` 或 `image`，同名 ID 在不同角色列表中不会混用。服务器从当前数据库配置解析地址、模型、协议和认证头；客户端提供的目标 URL、模型名称和认证头不能覆盖保存的连接。

- 文字、流式文字、视觉评分、图片适配器接入引用请求。
- ComfyUI 使用服务器保存的工作流；浏览器只传提示词、画幅、种子、参考图等生成输入。连通性测试不等于工作流生成验证。
- 请求配置选择器不再返回模型 API key 或 ComfyUI 工作流；仍返回格式化协议请求所需的模型元数据。
- 新任务、脚本重放、图片队列和视觉复审识别配置引用。显式引用已删除时不会改用活动配置、环境默认或旧 fallback。
- 图片任务只允许覆盖画幅和生成参数，不能覆盖地址、模型、协议、工作流或认证。读取历史任务 overlay 时同样执行限制，不能仅依赖新任务写入过滤。
- 文字和图片主请求拒绝重定向。HTTP 代理上游错误日志不再打印上游原文；这不是所有日志已经完成脱敏的声明。

## 兼容边界

没有引用的临时配置请求保留原有接口，用于设置页草稿连接测试等调用。本批不是移除所有旧接口，也不是完整授权或 SSRF 防护。

**后续批次已推进：** 配置 GET 已去除模型密钥，编辑使用保留/替换/清除语义，保存确认后清除输入，缓存不写入新模型 key；详见 MODEL_CREDENTIALS.md，历史缓存和非模型凭据等限制仍需注意。未保存的新 ID 请求会明确失败；保存状态与生成入口的联动 UX 仍待完善。

模型配置变更后，任务执行使用当前服务器配置；本批不提供可还原历史模型连接的版本化快照。协议在请求发出前被另一标签页修改的竞态仍需引入引用版本/能力协商治理。

## 验证证据

本批使用合成凭据、独立数据目录和本机模拟上游，不额外调用真实模型。

- 单元及 route 回归覆盖角色隔离、删除引用、嵌套引用、旧 overlay、地址覆盖、服务端脚本/评审解析、无密钥浏览器请求。
- 真实 Next 生产服务器 HTTP 测试覆盖文字、流式、视觉角色、图片、ComfyUI ping、404、无效角色及拒绝重定向。仅观察到保存的目标与模型；接收恶意覆盖/重定向的测试目标收到 0 次请求。
- HTTP 测试不是浏览器生成端到端，也不是 ComfyUI 工作流生成实测。
- `.codex/model-references-2026-09-20/http-smoke-result.json` 为本机证据，仅记录凭据匹配布尔值，不含真实密钥。
- 完整测试/类型检查/lint/生产构建证据在同目录 `final-verification-rerun.log`。该目录被 Git 忽略；项目文档保留验证范围，不能依赖忽略目录作为远端唯一记录。

真实 localhost:8317 模型的既有能力测试另见 `MODEL_COMPATIBILITY.md`；不要把本批模拟结果当成又一次真实模型调用。
