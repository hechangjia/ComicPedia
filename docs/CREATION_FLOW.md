# 创作提交与生成前检查

2026-09-20：五类创作表单共用同一提交边界，保留科普、百科、诗词、小说和小红书各自的输入内容。

## 本批行为

- 默认「先审分镜（推荐）」，请求使用 `pauseAfterScript: true`。没有图片模型也能先生成分镜；选择连续出图则必须有图片配置。
- 点击提交时重新读取配置快照，而不只依赖上一次渲染结果。读取中、保存中、同步错误、版本冲突均在模型调用前提示。
- 显式模型选择优先于默认模型；已删除选择报错，不静默切换。模型下拉框在零个或一个配置时仍展示当前状态，并跟随配置存储更新。
- 分镜数量只接受 1 到当前表单上限的整数，或自动。不使用 parseInt 截断小数或非法后缀。
- 生成前检查展示本次分镜、图片、视觉检查角色、格数和是否停下来审核。字段完整不等于模型能力验证通过；独立 VLM 缺失时提示文字模型视觉回退的限制。
- 同一次挂载期间以 ref 阻止同一时刻重复提交；失败可重试；成功后导航并清除草稿的待保存定时器。
- 高级设置展示当前有效预设，修改只发出字段增量，避免后续切换预设时错误保留旧的 pauseAfterScript 等计算值。各表单合并用户已有增量。
- 图片队列在轻量检查关闭时不再调用视觉评分器。当前队列仍顺序执行，界面明确提示并发参数不会提升实际并行度。
- 创作页收拢首次配置指引和灵感模板，呈现四步流程说明；类型切换更新 mode 查询参数并保留其他查询参数。流程说明并非新的可恢复向导。
