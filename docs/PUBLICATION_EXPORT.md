# 出版导出选项与预检

2026-09-20。本批将 PNG、PDF、ZIP 图片包与 Markdown 图片包接到统一选项，保留小红书与 Seedance 原入口。出版导出不是完整作品备份。

## 可用选项与执行语义

| 格式 | 真正生效的参数 |
| --- | --- |
| 共用 | 分镜选择（按作品原顺序）、缺图阻止/显式跳过、对话/旁白、场景说明、署名 |
| PNG | 每行 1/2/3 格、1×/2× 渲染、整图实际排版预览 |
| PDF | A4/Letter、纵向/横向、150/200/300 DPI、每页 1/2/4 格、5–25 mm 内容边距、封面开关、第一页实际排版预览 |
| ZIP/Markdown | 原始图片、README、export.json；正确文件扩展名、保留原分镜编号、已选择选项及跳过编号 |

`src/lib/export/options.ts` 提供 ExportOptions、buildExportPlan、尺寸预算与安全文件名。导出只操作分镜副本，不修改任务。file:// 引用转换为图片 API 地址，编号不因跳过缺图而重排。已有个人署名用作对话框初始值，可在本次导出中修改。

`ExportDialog` 使用原生模态 dialog，提供格式相关参数、初始关闭按钮焦点、Escape 关闭、关闭后回到下载按钮、忙碌状态和重复操作保护。生成期间不支持取消，界面要求保持页面打开；不得将关闭对话框描述成上游取消。

## 失败与预算

- 默认缺图阻止导出；只有显式选择 skip 才跳过未完成/无图片的分镜。已经标记完成的图片如果读取失败，仍停止本次文件生成，不用空白格或静默缺页冒充完整导出。
- PNG/PDF 渲染维度在创建大画布前校验：单边最多 16,384 px、单画布最多 3,200 万像素；PDF 全部页面合计最多 1 亿渲染像素。
- 图片包逐图读取，单图最多 20 MB，图像总计最多 128 MB；读取有 30 秒超时，HTTP 错误或不支持的 MIME 报错。ZIP 使用 STORE 避免重复压缩已压缩图像。
- 支持包内 PNG/JPEG/WebP/GIF；不将 HTML 错误页按 jpg 打包。响应 MIME 校验不等于完整图像解码或恶意文件安全认证。
- 下载反馈为“文件已生成并交给浏览器下载”，不声称用户文件系统已成功落盘。

## 仍需推进的范围

- 小红书、Seedance、复制长图/分享卡片及结果页另一套纯 Markdown 导出仍未统一参数/失败策略；保留原功能，不声称全部格式已完成重构。
- PDF 是栅格排版，不是可搜索/可访问的文字 PDF；现有长文字截断仍可能发生，界面已提示，并提供完整文字图片包替代。封面使用独立版式，内容边距不控制封面留白。
- 预览 PNG 为整图、PDF 仅第一页；没有多页缩略图导航。导出选项暂不跨会话保存；只有粗粒度准备/完成状态，无逐图进度和中途取消。
- PNG 固定 512 逻辑像素图格，内存预算不代表已计入源图片解码、JS 引擎和 jsPDF 全部开销。完整资源预检、极端长文本、巨幅输入与弱设备仍需更广泛验证。
- ZIP/Markdown 的清单记录参数，不是精确复现承诺：时间、浏览器字体、媒体变更仍可能影响重新导出。完整作品备份恢复、资源摘要/版本和数据迁移是单独主线。
- 服务端凭据域、生命周期一致性、真实模型到出版文件的完整验收仍未完成。整体目标保持 active。
