# 专用出版格式与复制/分享（2026-09-20）

本批在统一出版导出方案上增加小红书排版与视频分镜脚本配置；不涉及平台发布、真实视频生成或完整作品备份。

## 使用与行为

- 下载菜单全部九种出版格式使用同一个 ExportDialog。共用分镜选择、原始编号、文字/署名和显式缺图策略。
- 小红书分页宽度可选 1080/1440 px，每页固定 3:4；横竖图片均 contain-fit，不拉伸、不裁剪。对白/场景按实际测量排版，文字超过页面预算时报错，不静默截断。分页预览只展示第一页。
- 小红书长图使用同样的宽度与文字选项，高度随内容变化，不再标注为固定 3:4。图片比例不变。
- 视频 JSON/TXT 是本地分镜建议：可选 16:9/9:16/1:1、按旁白估算或每段固定 3–10 秒。纯脚本不要求图片已生成，参考图 ZIP 则要求所选图片可读取。
- 视频 ZIP 从本地图片 API 或可读取图片地址获取素材，使用 MIME 对应扩展名；script.json 的 referenceImage 指向包内 references 文件，保留原分镜编号。清单明确 providerCompatibilityVerified=false。没有对第三方视频 API 的兼容承诺。
- 复制长图/Web Share 文件生成复用 renderComicCanvas，图片失败上报，不再静默漏图；独立「分享卡片」仍是另一条实现，未在本批统一。
- 输出设置只影响导出副本，不修改任务。清单是出版参数记录，不是可恢复备份。

## 资源与失败边界

- 沿用单画布 3,200 万像素、单边 16,384 像素限制；分页图总渲染预算 1 亿像素、PNG 编码累计 128 MiB。
- 视频参考图沿用 checked image reader：HTTP/MIME 检查、单图 20 MiB、30 秒读取超时；合计 128 MiB。
- PNG 编码返回空、读取失败或文字预算超出均中止文件生成，不以缺页文件冒充成功。
- 这些预算不等于所有源图解码/JSZip 内存受控；Canvas 源图加载超时、解码预算、极端文本仍需进一步完善。
